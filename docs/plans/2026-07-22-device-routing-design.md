# Выбор устройств ввода и вывода из виджета

## Цель

Сделать подписи устройств под каналами реальными интерактивными переключателями маршрутизации SteelSeries Sonar. Каналы «Игра», «Чат», «Медиа» и «Музыка» выбирают физическое устройство вывода, канал «Микрофон» — физическое устройство ввода.

## Решение

Виджет использует тот же локальный HTTP API, что и установленный интерфейс SteelSeries GG. Список устройств загружается из `/audioDevices`, а текущие назначения — из `/classicRedirections`. В списках выбора остаются только активные не-VAD устройства: `render` для четырёх выходных каналов и `capture` для микрофона. Выбранное назначение меняется запросом `PUT /classicRedirections/{channel}/deviceId/{deviceId}`.

Нажатие на строку устройства открывает компактное меню поверх виджета. Меню не меняет размеры основного окна и не участвует в перетаскивании. Выбор закрывает меню, применяет маршрут через главный процесс и обновляет подпись только после успешного ответа Sonar. Нажатие вне меню и Escape закрывают его без изменений.

## Состояния и ошибки

- Текущее имя определяется сопоставлением `deviceId` из `/classicRedirections` с `/audioDevices`.
- При отсутствии назначения выводится «Не выбрано».
- Если подходящих устройств нет, меню показывает неактивную строку «Нет доступных устройств».
- Ошибка переключения не подменяет текущее имя; она кратко показывается в строке устройства, затем выполняется повторная синхронизация.
- Режим Sonar «Связать все выходы» не эмулируется виджетом: штатный API и последующая синхронизация остаются источником истины.

## Проверка

Автотесты покрывают фильтрацию устройств, построение состояния назначений, URL переключения и обработку ответа API. Ручная проверка выполняется на запущенном Sonar: открыть меню, выбрать другое устройство, подтвердить изменение через `/classicRedirections`, затем вернуть исходное назначение.
