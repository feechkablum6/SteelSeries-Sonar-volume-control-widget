# Отзывчивость виджета и меню по ПКМ — план реализации

> **Для реализации:** использовать TDD и выполнять шаги последовательно в текущем checkout.

**Цель:** устранить многосекундные блокировки кликов и добавить системное меню ПКМ с закрытием и автозапуском.

**Архитектура:** нативный адаптер выполняет блокирующие сообщения Explorer через worker-поток Koffi и освобождает удалённую память только после завершения callback. Главный процесс объединяет параллельные запросы снимка. Отдельный чистый модуль формирует действия меню и управляет штатным login item Electron для установленной и portable-сборки.

**Стек:** Electron 28, CommonJS, Node `node:test`, Koffi, Win32 User32.

**Файлы:**
