# Глобальное закрытие списка устройств

## Проблема

Окно виджета намеренно создано с `focusable: false`, поэтому DOM получает клики только внутри окна и обычно не получает клавишу Escape. Текущие обработчики renderer не могут обнаружить клик по рабочему столу или другому приложению.

## Решение

Пока список устройств открыт, главный процесс устанавливает два временных низкоуровневых Windows-хука: `WH_MOUSE_LL` и `WH_KEYBOARD_LL`. Мышиный хук реагирует только на нажатия кнопок и через `WindowFromPoint` определяет процесс окна под указателем. Если клик пришёлся не по окну текущего процесса, renderer получает команду закрыть список. Клавиатурный хук реагирует только на Escape.

Оба хука всегда вызывают `CallNextHookEx`, поэтому не блокируют ввод в других приложениях. Они снимаются сразу после закрытия списка, при уничтожении окна и перед выходом приложения. Окно остаётся неактивируемым и не появляется в Alt+Tab.

## Проверка

Автотесты покрывают внутренний и внешний клик, Escape, другие клавиши, идемпотентный запуск и обязательную очистку подписок. Ручная проверка выполняется на живом окне: открыть список, кликнуть в другой программе, снова открыть и нажать Escape, после каждого действия подтвердить закрытие и отсутствие перехвата последующего ввода.
