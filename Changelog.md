﻿## 2026-08-06

- Виджет больше не замирает после долгого бездействия: Chromium считал перекрытое окно рабочего стола скрытым и через пять минут замедлял синхронизацию с Sonar до одного обновления в минуту, а `requestAnimationFrame` перетаскивания останавливал совсем. Фоновое торможение и определение перекрытия отключены (`backgroundThrottling: false`, ключи `disable-renderer-backgrounding`, `disable-background-timer-throttling`, `disable-backgrounding-occluded-windows`, `disable-features=CalculateNativeWinOcclusion`).
- Сообщения Explorer идут через `SendMessageTimeoutA` с `SMTO_ABORTIFHUNG` и пределом 1 с на сообщение, 3 с на весь обход значков. Раньше зависший Explorer навсегда блокировал рабочий поток Koffi, промис обновления не завершался, и виджет больше никогда не перепривязывался к рабочему столу. Буфер в памяти Explorer не освобождается, если сообщение не было доставлено вовремя.
- Полный обход значков выполняется по поводу — при смене окна рабочего стола, изменении конфигурации экранов, выходе из сна и разблокировке — плюс раз в минуту как страховка. Проверка привязки осталась ежесекундной, но теперь стоит несколько `FindWindowEx` вместо сотни межпроцессных вызовов.
- Соединения с Sonar переиспользуются (keep-alive, не более четырёх сокетов), интервал синхронизации — 1 с, новый опрос не стартует поверх незавершённого. Проверка сертификата ослаблена только для клиента Sonar, а не для всего процесса.
- Удержание слайдера отслеживается указательными событиями и снимается по таймауту: раньше отпускание кнопки за пределами виджета оставляло флаг перетаскивания навсегда, и синхронизация молча останавливалась.
- Нативный адаптер Win32 переживает пересоздание окна, обработчик выбора устройства перенесён к остальным, временная диагностика убрана.
- Иконки, заголовки каналов, подписи устройств и бегунки приглушены: белое свечение вокруг иконок убрано, ореол бегунка уменьшен.
- Бегунок больше не оставляет призрачный след при перетаскивании — слайдер вынесен в отдельный слой композитора, иначе окно с прозрачным фоном не перерисовывало область свечения.
- Бегунок выровнен по декоративной полосе: `margin-top` бегунка исправлен с -3px на -4px, замер готового кадра показал сдвиг на пиксель вправо после поворота слайдера.
- Список выбора устройства стал плотнее и тише: заголовок убран, выбранное устройство идёт первым, строки разделены тонкой линией вместо цветного фона, галочка выровнена по колонке. Появление — проявление из лёгкого размытия со сдвигом вверх (0,18 с), с отключением анимации при системной настройке уменьшения движения.
