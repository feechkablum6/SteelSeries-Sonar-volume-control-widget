# Sonar Glass Widget

Виджет рабочего стола для управления аудиоканалами SteelSeries Sonar.

![sonar-widget](preview.png)

Живёт прямо на рабочем столе в виде прозрачной панели и позволяет менять громкость каналов Sonar (игра, чат, музыка, микрофон и другие), не открывая приложение SteelSeries GG. Все изменения сразу отражаются в Sonar.

## Возможности

- Управление громкостью каналов Game, Chat, Media, Music и Mic в реальном времени
- Выбор реального устройства вывода для каждого канала и устройства ввода для микрофона
- Кнопка динамика для отключения и включения звука канала
- Прозрачный интерфейс в стиле glassmorphism
- Автоматическая синхронизация со SteelSeries GG
- Настоящий слой рабочего стола: обычные окна естественно перекрывают виджет
- Виджет не появляется в панели задач и в Alt+Tab
- Перетаскивание за верхнюю полосу; ярлыки рабочего стола служат препятствиями при перетаскивании
- Автоматическое восстановление после перезапуска Explorer
- Сохранение позиции между запусками и автозапуск с Windows
- Системное меню по правому клику: переключение автозапуска и полное закрытие виджета

## Требования

- Windows 10/11
- SteelSeries GG с включённым Sonar
- Node.js 16+ для разработки

## Установка

### Готовая сборка

1. Скачайте последний выпуск из раздела [Releases](../../releases).
2. Запустите установщик или portable-версию.
3. Виджет автоматически добавится в автозапуск Windows.

### Из исходного кода

```bash
# Клонировать репозиторий
git clone https://github.com/feechkablum6/SteelSeries-Sonar-volume-control-widget.git
cd SteelSeries-Sonar-volume-control-widget

# Установить зависимости
npm install

# Запустить в режиме разработки
npm start

# Собрать исполняемый файл
npm run build
```

## Использование

- Перетаскивайте виджет за верхнюю полосу.
- Слайдеры управляют громкостью каналов.
- Значок динамика включает и выключает звук.
- Нажмите на название устройства под каналом, чтобы выбрать другой выход или вход Sonar.
- Нажмите правой кнопкой по виджету, чтобы включить или отключить запуск вместе с ПК либо полностью закрыть приложение.
- Виджет не проходит сквозь ярлыки и не может быть установлен поверх них.
- Обычные окна перекрывают виджет без его скрытия и повторного показа.
- Изменения синхронизируются со SteelSeries GG в реальном времени.

Перед запуском убедитесь, что SteelSeries GG запущен и Sonar включён, иначе устройства не будут найдены.

## Технологии

- Electron 28
- Koffi для вызовов Windows API
- Vanilla JavaScript, CSS Glassmorphism
- Взаимодействие с Sonar основано на открытой библиотеке [steelseries-sonar-py](https://github.com/Mark7888/steelseries-sonar-py) (обратное проектирование неофициального API SteelSeries Sonar)
